# Contributing to Mugen Deej

Thank you for helping improve Mugen Deej.

## Before opening an issue

- Check the latest release.
- Reproduce the problem with a clean `config.json` when practical.
- Attach the relevant section of `logs/mugen-deej.log`.
- Do not post passwords, tokens, private paths, or unrelated personal information.

## Bug reports

Please include:

- Mugen Deej version;
- Windows version;
- controller board and USB–serial chip;
- connection mode and COM port;
- exact reproduction steps;
- expected and actual behavior;
- relevant log lines and screenshots.

## Pull requests

Keep changes focused. Update documentation and `CHANGELOG.md` when behavior changes. Preserve both Russian and English UI text for user-facing additions.
