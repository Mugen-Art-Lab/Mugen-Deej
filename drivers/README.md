Mugen Deej driver folder / Папка драйвера Mugen Deej

The program downloads the official CH340/CH341 installer here only after the user presses the driver button. Before execution, the digital signature is checked for a WCH/Qinheng publisher.

Программа загружает сюда официальный установщик CH340/CH341 только после нажатия кнопки установки драйвера. Перед запуском проверяется цифровая подпись издателя WCH/Qinheng.
