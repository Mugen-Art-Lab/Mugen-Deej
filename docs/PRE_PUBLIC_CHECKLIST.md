# Pre-public checklist

- [ ] README and README_RU clearly acknowledge the original deej project.
- [ ] LICENSE identifies MrSoichi / Mugen Art Lab as the copyright holder for Mugen Deej code.
- [ ] THIRD_PARTY_NOTICES.md is present.
- [ ] No personal `config.json`, logs, downloaded driver installers, tokens, or private paths are committed.
- [ ] The release archive starts cleanly on a second Windows computer.
- [ ] `Mugen-Deej-0.8.3.zip` and its SHA-256 file are attached to the GitHub release, not committed to the source tree.
- [ ] Release notes describe the build as a release candidate / tested build rather than promising universal compatibility.
- [ ] Repository visibility is changed only after reviewing the full Git history.
